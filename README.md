# wellmanifest/jsonl

`wellmanifest/jsonl` is the HOME pack for deterministic JSON Lines framing of
DSL records. Product runtimes and semantic packs such as `wellmanifest/logs`
ADOPT it; the standard does not define log-event meaning or execution authority.

The first governed ticket will define UTF-8/LF framing, bounded records,
canonical hashing, strict LLM output, and adapters for `wellmanifest/dsl` plus
declared `autogrammar/*` grammars.
